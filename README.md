# 基于机器学习的肽酶超家族智能归类研究——以抑制剂多维特征谱为核心的分类框架构建

> 利用抑制剂理化与结构特征，构建可自动判别肽酶所属家族的多分类模型，为蛋白酶靶向药物设计提供归类基础。

## 一、方法

- **模型**：FT-Transformer（特征标记化 Transformer）

- **输入**：表格字段（数值列 + 类别列）
- **训练规模**：11174 条样本，14 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
