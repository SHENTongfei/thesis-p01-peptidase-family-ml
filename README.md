# 基于机器学习的肽酶家族智能分类研究——抑制剂维度的多分类模型构建

> 用机器学习对 11174 条肽酶-抑制剂记录进行 14 类家族自动分类，构建抑制剂类型识别基线。

## 数据一览

| 文件 | 行数 | 用途 |
|---|---|---|
| `data/p01_main.tsv` | 11174 | 主训练集 |
| `data/p01_ext1.tsv` | 1200 | 外部验证集 1 |
| `data/p01_ext2.tsv` | 5000 | 外部验证集 2 |

数据来源：NCATS 肽酶-抑制剂标注数据


## 技术路线（摘要）

化合物 **Morgan 分子指纹 (2048 维)** ⊕ 靶点 **ESM2-150M 蛋白语言模型嵌入 (640 维)**
→ **GPU 多层感知机**（动态扩缩批训练）→ 活性档位预测（HIGH/MOD 或多分类）。

- 内部验证：主训练集 80/20 分层切分
- 外部验证：ext1 / ext2 两个独立通道全量推理
