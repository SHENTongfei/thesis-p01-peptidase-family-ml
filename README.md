# 融合分子指纹与梯度提升树的凝血酶抑制剂活性机器学习预测

> 以化合物 Morgan 分子指纹为输入，构建判别凝血酶抑制剂活性的二分类模型，为抗血栓药物的虚拟筛选提供可复现的计算工具。

## 一、方法

- **模型**：XGBoost 梯度提升树（Morgan 分子指纹）
- **输入**：Morgan 分子指纹（2048 bit）
- **训练规模**：545 条样本，2 类
- **标签协议**：act（活跃 / 非活跃）
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练

## 二、成绩

| 指标 | 数值 |
|---|---|
| 内部 CV AUC | **0.9647 ± 0.0128** |
| 样本量 | 545 |
| 正例占比 | 0.517 |
| 是否通过 0.7 质量门 | 是 ✅ |
