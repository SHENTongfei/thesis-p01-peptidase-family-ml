# 基于机器学习的肽酶超家族智能归类研究——以抑制剂多维特征谱为核心的分类框架构建

> 利用抑制剂理化与结构特征，构建可自动判别肽酶所属家族的多分类模型，为蛋白酶靶向药物设计提供归类基础。

> ⚠️ **诚实提示（重要）**：本数据集的可用特征仅有抑制剂的**身份类标识符**（`inhibitor_class` 1776 类、以及原始 `inhibitor_name` 自由文本），**不含抑制剂的分子结构描述符**。
> 经对照实验量化：仅用 `inhibitor_name` 记忆即可达到 **87.4%** 准确率、仅用 `inhibitor_class` 即可达到 **74%** 准确率，而纯亲和力数值 `kd` 几乎不能区分家族（≈25%）。
> 因此报告的 **CV AUC = 0.9608 并非真实的结构-活性预测能力，而是模型对化合物身份的记忆**。
> 该结果应理解为『抑制剂身份元数据与肽酶家族标签的一致性验证』，而非可外推的预测模型。
> 若需真实的预测能力，必须引入抑制剂的**分子结构（SMILES / 分子图）**作为特征——当前数据缺失该信号。

## 一、方法

- **模型**：FT-Transformer（特征标记化 Transformer）

- **输入**：表格字段（数值列 + 类别列）——注意：类别列均为抑制剂身份标识符，非分子结构
- **训练规模**：11174 条样本，14 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练

## 二、成绩（已诚实降格）

| 指标 | 数值 |
|---|---|
| 名义内部 CV AUC | 0.9608 ± 0.0034（⚠️ 含身份泄漏，不可信） |
| 身份记忆上限（仅 inhibitor_name） | 0.8740 |
| 身份记忆上限（仅 inhibitor_class） | 0.7400 |
| 纯亲和力（kd）可分性 | ≈ 0.25（不可用） |
| 是否构成有效预测模型 | **否（存在结构性信息泄漏）** |
